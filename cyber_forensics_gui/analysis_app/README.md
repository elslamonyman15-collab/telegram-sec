# Cyber Forensics Report Analyzer - User Guide

## What is this?

This is a **user-friendly tool** that analyzes the forensic reports generated by the Cyber Forensics Toolkit and presents the findings in plain, easy-to-understand language.

## Who is this for?

This tool is designed for **regular users** who may not have technical expertise in cyber forensics. It translates complex technical findings into simple explanations and actionable recommendations.

## How to Use

### Step 1: Generate Reports
First, run the main Cyber Forensics Toolkit to generate forensic reports:
- Run `2.bat` OR
- Run `cyber_forensics_gui.py` and perform a scan

This will create a `Cyber_Forensic_Report` folder on your Desktop with all the forensic data.

### Step 2: Open the Analyzer
Double-click `start_analyzer.bat` to launch the Report Analyzer.

### Step 3: Analyze Reports
1. The analyzer will automatically look for reports in `Desktop\Cyber_Forensic_Report`
2. If your reports are in a different location, click "Browse" to select the folder
3. Click "🔎 Analyze Reports" to start the analysis

### Step 4: Review Findings
The analyzer will organize findings by severity:

- **🔴 Critical** - Immediate action required (e.g., active attacks, malware)
- **🟠 High** - Important issues that should be addressed soon
- **🟡 Medium** - Issues that should be investigated
- **🟢 Low** - Minor issues or informational items
- **🔵 Info** - General information about your system

### Step 5: Follow Recommendations
Click the "💡 Recommendations" tab to see prioritized actions you should take to secure your system.

## Understanding the Findings

Each finding includes:

1. **Category** - What area of your system is affected (Network, Process, User, etc.)
2. **Title** - A simple summary of what was found
3. **What happened** - Plain language explanation of the issue
4. **What you should do** - Clear, actionable recommendation

## Common Findings Explained

### Network Findings
- **Suspicious port detected**: Your computer connected to a port commonly used by hackers
- **High number of connections**: Unusually many network connections (possible malware communication)

### Process Findings
- **Suspicious process detected**: A program that hackers often use was found running
- **Hidden processes detected**: Programs trying to hide themselves (possible malware)

### User Findings
- **Multiple administrator accounts**: More admin accounts than normal (security risk)
- **Disabled user accounts**: Old accounts that are disabled (cleanup needed)

### Persistence Findings
- **Startup item in suspicious location**: A program starting from an unusual place
- **Many scheduled tasks**: Lots of automated tasks (some may be malicious)

### File System Findings
- **Recently modified executables**: Programs changed recently (possible infection)
- **Files in suspicious location**: Programs in temporary folders (suspicious)

### Security Findings
- **Failed login attempts**: Many failed password tries (possible hacking attempt)
- **Suspicious PowerShell activity**: Automated commands being run (possible malware)

## What to Do If You Find Critical Issues

1. **Don't panic** - The tool is designed to help you understand and fix issues
2. **Disconnect from the internet** - If you suspect active malware
3. **Follow the recommendations** - Each critical finding has clear steps
4. **Seek professional help** - If you're unsure, contact IT support or a security professional

## Tips

- **Run regular scans** - Check your system periodically
- **Keep reports** - Save old reports to compare with new ones
- **Review all findings** - Even low-severity items can provide useful information
- **Update your system** - Keep Windows and software updated to prevent issues

## Need Help?

If you don't understand a finding or recommendation:
1. Click on the finding to see more details
2. Check the "Recommendations" tab for prioritized actions
3. Contact your IT support or a security professional for assistance

## Technical Details (For Advanced Users)

The analyzer reads the following report files:
- `Network_Deep_Analysis.txt`
- `Process_Anatomy.txt`
- `User_Privileges_Audit.txt`
- `Persistence_Mechanisms.txt`
- `Modified_Files_Forensics.txt`
- `Firewall_And_Hosts_Integrity.txt`
- `Security_Event_Logs.txt`
- Registry hives (from REGISTRY folder)
- Memory information (from MEMORY folder)
- Advanced artifacts (from ARTIFACTS folder)
